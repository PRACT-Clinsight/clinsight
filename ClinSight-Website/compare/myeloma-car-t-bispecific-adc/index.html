How this table was built

Selection rule: a record is included if its conditions or title mention myeloma and an intervention name matches one of: ciltacabtagene autoleucel, idecabtagene vicleucel (bb2121), anitocabtagene autoleucel, teclistamab, elranatamab, talquetamab, belantamab mafodotin. Records outside the ClinSight dataset are not shown, so this is not a complete list of myeloma trials.

Source: every cell is copied from the ClinicalTrials.gov record for that NCT ID. Enrollment may be the planned or the actual number depending on the record's status. No efficacy results are shown on this page; for outcomes, read the linked primary publication.

Reading the acronyms: the registry lists the same acronym on more than one record (DREAMM 7). Use the NCT ID to tell them apart.

Data retrieved from ClinicalTrials.gov API v2. Records can change; check the registry for the current version.
